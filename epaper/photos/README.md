`lenna.png` is the 512×512 test image from
<https://en.wikipedia.org/wiki/File:Lenna_(test_image)>, prepared with
`./prep-photo.py --fit cover`. It uses all four grey levels.

Wikipedia hosts it as non-free, so this repo isn't licensed to redistribute
it. Its model and the IEEE have asked people to stop using it. Replace it with
any picture; no code refers to it by name.
